Use this React Bits Border Glow component as the visual and interaction reference:

https://reactbits.dev/components/border-glow

--------------------------------------------------
1. FIRST — UNDERSTAND THE PROBLEM
--------------------------------------------------

The current implementation has too much visible glow inside the cards.

For example, on the Contact page:

- the large circular glow inside the form is too strong
- the interior of the card becomes visually illuminated
- the form fields compete with the glow
- the glow becomes the main visual element
- the design feels distracting and less professional

This must be fixed.

The glow should primarily appear around the CARD EDGE.

The card interior should remain clean and readable.

--------------------------------------------------
2. USE REACT BITS BORDER GLOW AS THE REFERENCE
--------------------------------------------------

Use the React Bits BorderGlow implementation and behavior as the reference.

The important behavior is:

The cursor approaches the edge
→ the nearest border area reacts
→ a localized glow appears
→ the glow follows the pointer position
→ the interior remains mostly unchanged
→ cursor moves away
→ glow fades smoothly

Do NOT turn the effect into:

- a spotlight
- a large radial light
- a center glow
- a giant aura
- a colorful blob
- a permanent gradient
- an animated background

The interaction must remain edge-focused.

--------------------------------------------------
3. IMPORTANT — REDUCE INTERIOR GLOW
--------------------------------------------------

This is the highest-priority fix.

The current implementation uses too much internal glow/fill.

Reduce or disable the interior color fill so that:

THE CARD SURFACE REMAINS CLEAN.

The BorderGlow should mostly affect:

- border
- immediate edge
- very subtle outer glow

Avoid strong light inside the entire card.

The user should notice the edge responding, not a bright orb appearing inside the card.

--------------------------------------------------

Use this as the baseline:

6. IMPORTANT — GLOW MUST FOLLOW THE CURSOR
--------------------------------------------------

The glow should be directional.

Example:

Cursor near top-left corner
→ top-left border glows

Cursor near right edge
→ right edge glows

Cursor near bottom
→ bottom edge glows

Cursor moves
→ glow moves with it

Cursor leaves
→ glow fades out

This directional edge response is the key interaction.
